# このリポジトリについて

少人数の読書会で一緒に読まれることを前提に書かれた、教養の読み物を置いています。試験対策ではなく、面白くて、ちょっと役に立つことを目指した読み物です。第1シリーズは「アメリカ50州」——地理と現代社会の地誌です。

## 正直の開示

各章の著者はペンネームであり、紙面の上の人物です。実在の研究者ではありません。実際の書き手はClaude(Anthropicの言語モデル)です。各章の事実の言明は執筆時に検証し、注に出典を記していますが、それでも誤りはあり得ます。各章の執筆時点と検証の記録は、章ごとの編集用ファイル(ファイル名に -check の付くもの)にあります。

## 読み方

- 読みやすいウェブ版があります: https://ykshm.github.io/geostudy/
- 各章は独立して読めます。どの章からでも、どの順でも。
- 注は各節の末尾にあります。本文が取り上げなかった話題と、「なぜ?」の答えは注に。
- 本文は中学の社会科程度の前提知識で読める水準、注は大人の読者向けです。

## 構成

- CONCEPT.md — この読み物が何であるかを定めた文書(執筆用)
- WRITING.md — 紙面の書式と執筆の手順(執筆用)
- authors/ — 著者プロフィールと、章と著者の割り振りの一覧
- text/usa/ — 第1シリーズ: アメリカ50州(最初の章はテキサス、tx.md)
- 各章フォルダの img/ と -check ファイル — 図版と、編集用の検証記録
