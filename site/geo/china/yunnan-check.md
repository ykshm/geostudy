## 検証(2026-09-08)

1. `python3 site/build.py` — 警告・エラーなし(31章)。maps/china-yunnan.html が生成された。
2. `_site/` を localhost:8901 のHTTPサーバで開き、同梱Chromium+Playwrightで確認した。リモートの実行環境のため、ブラウザからは外部(地図タイル・Commonsの写真)を遮断して検証し、URLの到達性はcurlで別途確認した(MAPS.md 6節の但し書きに従う):
   - [x] 章ページに📍地名リンクが13個付く(各節の初出、data-i対応)。地図パネルの要素と章末「おまけ: 地図で歩き直す」節が生成される
   - [x] 通常モード: ピン13・チップ14(「全体」+13)。ピンの節番号表示は 1,1,1,2,3,4,4,4,5,6,6,7,7 で places の sec と一致
   - [x] チップ(玉渓)クリックで該当地点の吹き出しが開き、text が表示される
   - [x] `?rich`: マーカー22(places 13+📷snaps 5+✦extras 4)。吹き出しに写真・rich文・クレジットが出る。写真srcは upload.wikimedia.org の500pxサムネイル
   - [x] 写真タップで全画面のライトボックスが開き、キャプション(名前+クレジット)が出る。1280px版への差し替えを要求する(遮断環境ではonerrorで500px版に戻る設計どおりの挙動を確認)
   - [x] モバイル幅(390px)でもマーカー描画とチップ→吹き出しが動く
   - [x] 他章への影響なし: 広東の地図はピン12のまま、テキサス章ページも開く。JSエラーなし
3. 写真URLの到達性: JSONに載せた500pxサムネイル22本は、全点をcurl(またはサムネイルの実取得)でHTTP 200確認済み。タップ拡大用の1280px版は、原画像の幅が全点1280px以上であることをAPIのサイズで確認した上で、5点(元陽・老勐・玉渓・老班章・章図7)を抽出してHTTP 200を確認した。
4. レート制限の記録: 検索・メタデータ・取得の各段で429が頻発。70〜100秒空けての再試行と、リクエスト間22〜30秒の待ちで全点取得。Special:FilePathの原寸URLが連続429になる場合、APIのthumburl(標準幅)経由に切り替えると通った。
