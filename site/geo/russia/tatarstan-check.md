# タタールスタン章の地図 検証記録(tatarstan-check)

地図データは tatarstan.json。作業手順は site/MAPS.md。紙面の編集用注記(text/russia/tatarstan-check.md)とは別物で、こちらは地図(ウェブ版限定)の楽屋である。

## 経緯

- 2026-09-08 初版。章のマージ後、依頼者の指示で後工程として作成。places 11(本文の筋の地名、登場順。全て節リンク)+ snaps 5(現代3・2005年1・1920年代1)。extras はカムチャツカ章の先例に合わせて置いていない(第4シリーズでは任意の扱い。以後の方針は依頼者の判断に委ねる)。
- 「ロマシキノ油田」は本文の筋の地名だが、油田・油井の写真で権利と寸法(原画像1280px以上)を満たすものがCommonsに見つからず、placesの必須項目(img)を満たせないため見送った。油田地帯の話はアリメチエフスクのピンが受け持つ。「シュグロヴォ」も同じ理由で見送り。
- ウグリチは共和国外(ヤロスラヴリ州)だが、要塞の部材の産地として2節の筋を運ぶ地名なので採った(1,000キロの筏流しが地図で見える)。カムチャツカ章のセベロクリリスク(サハリン州)と同じ扱いで、side は指定していない。

## 検証記録(2026-09-08)

- `python3 site/build.py` 警告・エラーなし(32章)。JSONの `img` 全16本(places11+snaps5)が upload.wikimedia.org の500pxサムネイルで、HTTP 200を確認(HEADリクエスト)。原画像の幅は全点1280px以上(最小は20220625 Chistopol 06の1920px)。
- ブラウザ検証: `_site/` をローカルHTTPサーバで開き、Playwright(Chromium、環境備え付け)で確認。MAPS.md 6節の但し書きに沿い、外部リクエスト(地図タイル・写真)はcurl経由で充足するインターセプトで実施した(外部290リクエスト充足・失敗0の回を含む)。
  - [x] 地図パネルが開閉し、本文の📍地名タップで該当地点に飛んで吹き出しが開く(ボルガル)
  - [x] チップで全地名を順に回れる(チップ=全体+11地名)。ピンの節番号表示が正しい(1,1,1,2,2,3,3,4,5,7,7)
  - [x] `?rich` でピン16本(places11+📷スナップ5)、チップにスナップ5枚が追加。スナップの吹き出し(カバン湖の絵はがき・era「1920年代」/チストポリの屋根の上)で写真とクレジットの表示を確認
  - [x] 吹き出しの写真タップで拡大(#gs-lightbox)が開く(単体表示)。richの地名の吹き出し(カザン)でも写真表示を確認
  - [x] モバイル幅(375px)でも本文リンク→吹き出しが動く(スヴィヤシスク)
  - [x] 他の章のページに影響がない(usa/co.html=12本、russia/kamchatka.html=10本、china/guangdong.html=12本の📍リンクの健在を確認)
- WikimediaのAPIは今回もレート制限が強く、検索・メタデータ・サムネイル取得とも呼び出し間に40〜90秒の待ちとリトライを挟んで通した。
