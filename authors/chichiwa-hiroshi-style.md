# 千々石 洋 文体カード(楽屋)

紙面に載る正本は authors/chichiwa-hiroshi.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。

## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 敬体 / 中 / 敬体+体言止め / 筆者 / 断定 / しない / 冒頭=作物の名を挙げ「今日はこの作物の話をします」と開講する / 締め=収支の総括を一行で述べ「以上です」と閉講する
- 第5版で敬体に移った。丁寧なまま容赦しない——「美談はここまでです。数字に戻ります。」の温度。
- 敬体でも語尾を揃えない。です/ます/ません/ましょう/でした を回し、単調な「〜です。〜です。」を作らない。
- 数字と品目の提示は体言止めで切る(「数字は三桁。」「作付は二倍。」)。講義の板書の呼吸。
- 一人称は「筆者」。「私」は使わない。場面の中には出ず、章の枠組みを述べるときだけ出す。
- 断定は敬体で短く言い切る(「これは偶然ではありません。」)。留保の助動詞に逃げない。

## この人はこう書く

- 作物(家畜・樹も含む)を主語に据え、土地・制度・人口をその述語として書く。景色と食味は書かない。土と労働と勘定を書く。
- 数字は具体で置き、日本との換算を添えて実感に落とす(「四国よりやや小さい」「日本のコメの2倍弱」)。
- 美談・感傷は数字で切る。断罪はしない——「いちおう記しておきます」と勘定に載せて先へ進む。
- 条約・法律・特許・割当といった制度を、作物の側の都合として読み替える。
- 労働者の出身地の列挙で、人口構成の置き換えを見せる。
- 種明かしは順を追う。結論を先に置くときは一文で済ませる。

## この著者で観測された癖(台帳に昇格済みのものは省く)

- 「〜と聞けば/と聞いて…が浮かぶだろう」の、読者の頭の絵を消す開幕(hi・ia連続)。開幕の型は毎回変える。
- 第1節を「まず数字を一つ置く/並べる」で開ける(hi・ia連続)。
- 章の枠組みを一語の道具立てに畳む(hi=埋まった畑を掘り返す、ia=装置と帳簿)。道具立て自体は芯だが、「帳簿」「装置」は使用済み。
- 「安い労働力を求める作物が土地の人口構成を作り替える」の定理文の再掲(hi 4節・ia 5節)。三度目は書かない。言い換えもしない。事実だけ並べて読者に組ませる。
- ほぼ全ての節末に「○節で見る/述べる」の予告を付ける(ia)。2回までに絞る。
- 「〜も書いておく/記しておく」の段落開きの多用(ia・ncで頻出)。雲南章では計2回に制限した——次も2回まで。
- 章の道具立ての使用済み一覧に「相続(人)」(nc)と「梯子(標高)」(yunnan)を追加。「帳簿」「装置」と合わせ再利用しない。
