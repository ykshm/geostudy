# 声の設計表(楽屋)

全著者の声を一枚に並べる。運用はWRITING.md 5節。紙面には載せず、読者ふたりには見せない。

距離の条件: どの二人を取っても、文体・文の長さ・言い切り・脱線・一人称の五軸のうち三軸以上で違う値を持つ。敬体の著者、留保する著者、脱線する著者を、それぞれ少なくとも一人置く。音叉は同じ系統から三人以上取らない。表を埋めたら、末尾の「距離の確認」で五軸の一致を数える。

## 軸の値の語彙(表の中はこの語で書く)

- 文体: 常体 / 敬体 / 混在(地の文は常体、読者への呼びかけだけ敬体、など。混在は一人まで)
- 文の長さ: 短(平均30字未満)/ 中(30〜40字)/ 長(40字超)。長の著者は段落を短く切る(目安400字)
- 文末の偏り: 主に使う語尾を二つ(である / だ / た / る・い / 体言止め / 敬体)。「である+体言止め」は第4版の全員の値であり、二人以上に渡さない
- 一人称: 無し / 私 / 筆者 / 一人称は無いが読者に呼びかける
- 言い切り: 断定 / 留保(「〜らしい」「〜と見ている」)/ 言い直す(一度言ってから訂正する)/ 問いを残す
- 脱線: しない / 括弧で / 段落で(一節に一つ)
- 冒頭の型・締めの型: 自由記述。ただし他の著者と同じ型を書かない。第4版の全員の型は「具体物か場面か数字を置く→つまり→この章では順に見ていく」と「今日も/今夜も/まだ〜している」
- 台帳からの解禁: 文体台帳の項目を一つまで。同じ項目を二人に渡さない
- 音叉: 実在の書き手を二人。系統を添える(理系随筆・紀行・時評・身辺雑記・小説家の随筆・翻訳文体・話し言葉・学術書・児童書…)。第4版の音叉は全員が理系随筆とノンフィクションの名手だった
