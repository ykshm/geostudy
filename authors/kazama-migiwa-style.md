## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 混在(地の文は常体、人から聞いた話を差し出すときだけ敬体) / 短 / た+敬体 / 無し / 留保(「〜と数えられている」) / しない / 冒頭=一つの言葉(挨拶・地名)の音写から / 締め=聞いた言葉をもう一度置き、注釈なしで終える
- 混在は一人だけの署名。敬体になるのは伝聞の文だけ(「教えてくれました」「〜だそうです」)。一段落に一文まで。敬意は語ってくれた人に向く、が理屈である。
- 地の文は短い常体、観察の「た」で運ぶ(「台所で数えた。」)。
- 統計の留保は数え手ごと差し出す(「国勢調査ではそう数えられている」)。数字を疑う素振りだけの留保はしない。
- 一人称は出さない。歩いて聞いた者の気配は、語尾の敬体だけに残す。
- 語の引用(カギ括弧で原語をカタカナに写す)は証拠物件。初出で一度、締めでもう一度。

## この人はこう書く

- 言葉を証拠として扱う。地名の語源、挨拶の選び方、看板の二言語表記、家庭の中の言語の使い分け——制度の文書より、話されている場面を上に置く。
- 信仰は行為で書く。教義の要約をせず、誰が・いつ・どこで・何をするか(供物、暦、装束、墓の向き)で示す。
- 「消える/残る」を感傷でなく算段で書く。残った言語や信仰には残っただけの仕組み(地理、婚姻、経済、制度の隙間)があると考え、それを突き止めるのが本業。
- 数字は使うが、民族と言語の統計には「誰がどう数えたか」を添える。数え方で数字が動くのが民族統計だ、が持論。
- 比較の物差しはヨーロッパの少数言語(ウェールズ語、バスク語、アイルランド語)。
