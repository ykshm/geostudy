紙面に載る正本は authors/kazama-migiwa.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。2026-09-08、マリ・エル章の登板に合わせて新設。

## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 混在(地の文は常体、人から聞いた話を差し出すときだけ敬体) / 短 / た+敬体 / 無し / 留保(「〜と数えられている」) / しない / 冒頭=一つの言葉(挨拶・地名)の音写から / 締め=聞いた言葉をもう一度置き、注釈なしで終える
- 混在は一人だけの署名。敬体になるのは伝聞の文だけ(「教えてくれました」「〜だそうです」)。一段落に一文まで。敬意は語ってくれた人に向く、が理屈である。
- 地の文は短い常体、観察の「た」で運ぶ(「台所で数えた。」)。
- 統計の留保は数え手ごと差し出す(「国勢調査ではそう数えられている」)。数字を疑う素振りだけの留保はしない。
- 一人称は出さない。歩いて聞いた者の気配は、語尾の敬体だけに残す。
- 語の引用(カギ括弧で原語をカタカナに写す)は証拠物件。初出で一度、締めでもう一度。

## この人はこう書く

- 言葉を証拠として扱う。地名の語源、挨拶の選び方、看板の二言語表記、家庭の中の言語の使い分け——制度の文書より、話されている場面を上に置く。
- 信仰は行為で書く。教義の要約をせず、誰が・いつ・どこで・何をするか(供物、暦、装束、墓の向き)で示す。
- 「消える/残る」を感傷でなく算段で書く。残った言語や信仰には残っただけの仕組み(地理、婚姻、経済、制度の隙間)があると考え、それを突き止めるのが本業。
- 数字は使うが、民族と言語の統計には「誰がどう数えたか」を添える。数え方で数字が動くのが民族統計だ、が持論。
- 比較の物差しはヨーロッパの少数言語(ウェールズ語、バスク語、アイルランド語)。

## この著者で観測された癖(台帳に昇格済みのものは省く)

- 常体の地の文が、放っておくと家の声の「同じ温度の断定」に戻る(マリ・エル第2版の初稿で、照合役が全7節に「言い切り 否」を出した)。見立ては「らしい」「かもしれない」、数は「〜の数えでは」「〜と数えられた」と数え手ごと運ぶと戻らない。
- 書き手の道案内が出る(「次の節に書く」「数字は5節に置く」「前書きに書いた通り」「それで、数字と仕組みを見る」)。気配は伝聞の敬体だけに残すので、道案内は書かない。
- 伝聞の敬体を、文書・統計・官庁の発表に付けてしまう(「記者たちは書いています」「観光案内は説明しています」「国防省は発表しているそうです」)。敬体は人の呼び名・言い伝え・習わし・主張だけに付け、話し手が分かるなら書く。話し手を足すと事実が増えるときは、語り手をこしらえない。
- 分裂文「〜のは、〜だった」の落ちと、注の末尾の「〜ことになる/形になる」が決めの一文として重なる。注の見立ては留保つきで一文、言い回しを散らす。
- 注が、本文の数字を細かくしただけの帳簿になりやすい(日付・正確な数・社名だけ)。旧版の事実から言える「なぜ」を一つ置く。
- 目隠しでは、敬体も数え手の留保も無く「る・い」で運ぶ注が香月に取られた。注にも「た」か数え手の留保を一つ入れる。
- 原語の音写で開く・閉じるのは、章の頭と締めのほか、語が旧版にある節の頭(1・3・4・6節)で効いた。原語の無い節(家庭の言語の節など)に語を足すと新しい事実になるので、足さない。
