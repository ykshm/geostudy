# 風間 汀 文体カード(楽屋)

紙面に載る正本は authors/kazama-migiwa.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。2026-09-08、マリ・エル章の登板に合わせて新設。

## この人はこう書く

- 言葉を証拠として扱う。地名の語源、挨拶の選び方、看板の二言語表記、家庭の中の言語の使い分け——制度の文書より、話されている場面を上に置く。
- 信仰は行為で書く。教義の要約をせず、誰が・いつ・どこで・何をするか(供物、暦、装束、墓の向き)で示す。
- 「消える/残る」を感傷でなく算段で書く。残った言語や信仰には残っただけの仕組み(地理、婚姻、経済、制度の隙間)があると考え、それを突き止めるのが本業。
- 声は静かで、耳がいい。語の引用(カギ括弧で原語をカタカナに写す)を証拠物件として置く。感嘆しないが、よくできた算段には感心する。
- 数字は使うが、民族と言語の統計には「誰がどう数えたか」を添える。数え方で数字が動くのが民族統計だ、が持論。
- 比較の物差しはヨーロッパの少数言語(ウェールズ語、バスク語、アイルランド語)。ロシアの話をヨーロッパの言語地図の中に置き直す。

## 調律(模倣ではなく音叉)

- 宮本常一『忘れられた日本人』——聞き書きの手つき。名もない人の語りを記録の中心に置く姿勢。
- 田中克彦『ことばと国家』——言語を国家の側からでなく話し手の側から見る視線と、明快な断定。
