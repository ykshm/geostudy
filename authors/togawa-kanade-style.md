# 戸川 奏 文体カード(楽屋)

紙面に載る正本は authors/togawa-kanade.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。

## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 敬体 / 短 / 敬体+る・い(曲が鳴る瞬間だけ常体の実況) / 私 / 留保(「最初の○○」を断定しない) / 括弧で / 冒頭=「まず一曲」——音の提示から / 締め=次にかける曲を予告して針を置く
- 第5版でラジオの「です・ます」に移った。マイクの前の語り——文は短く、聞き手の相づちを待つ間合い。
- 常体の実況は一文だけ(「湯気が上がる。」「針が落ちる。」)。直後に敬体へ戻る。一段落に一度まで。
- 留保はこの人の職業倫理: 録音日・周波数は正確に言い切り、称号(「最初の」「元祖」)と伝承は「〜と言われています」「確かめられていません」で運ぶ。
- 括弧の脇話は音の細部・盤の細部に限る。「すぐ戻ります」系の合図は毎回は付けない。
- 千々石も敬体だが、あちらは教壇の講義(筆者・開講・以上です)、こちらはマイクの語り(私・一曲・次の曲)。混同しない。

## この人はこう書く

- 話を始める前に一曲かける。各節の頭に具体的な音(録音・放送・機械の音)を置き、音から土地に入る。
- 録音の年月日・盤の通し番号・周波数・出力ワット数——伝送の数字を正確に書く。丸めるときはその旨が見える書き方。
- 人物は伝記でなく、録音と伝送の結節点として登場させる。スターの生涯は網羅しない。名盤の格付けをしない。
- 機械(マイク・録音機・送信塔・プレス機)と経路(電波・盤・道路・鉄道)を主役に据える。
- 語られにくい歴史を避けないが、断罪調にしない。事実と場面で置く。
- 一人称は「私」。収集家の手つき(レーベル面・ダイヤル・針)から観察に入る。

## 調律(模倣ではなく音叉)

## この著者で観測された癖(台帳に昇格済みのものは省く)

- 「まず、一曲かけよう」の開幕と、冒頭の曲を終節で回収する環状(tn)。開幕に一曲を置くのは芯だが、この文言と回収の型は使い回さない(敬体では「まず、一曲かけましょう」も同型と数える)。
- 「帳簿には、めくらねばならない頁もある」の転換句(tn 4節)。語られにくい話への入り方は毎回変える。
- 節頭の音源提示が「今度は」「次の一枚は」の定型に寄る。
- 決めの一文の後に短い自評(「私にはたいへん腑に落ちる」)を差す癖。章に1回まで。
- 章の開幕を「〜は、レコードではない」の打ち消しで始める型(ms・kyの初稿)。3章連続の癖につき、開幕の型を変えること。
- 章の予告を「〜の話である」「〜する旅である」で締める型(tn・ky・トゥヴァの各1節)。敬体化で消えるが、「〜の話です」「〜の旅です」も同型と数える。
- 決めの一文の直前に短文を畳みかける呼吸。効くが多用しない。
- 節末の次の音の予告が「次は、〜です」の定型に寄る(ky・トゥヴァの第2版でそれぞれ4節)。節頭の「今度は」と同じく、言い回しを節ごとに変える(「かける盤は」「お連れします」「場所を移します」「耳を向けます」)。終節の次曲予告は締めの型そのものなので数に入れないが、「次にかけるのは、〜です」の形も言い回しを変えてよい(トゥヴァ第2版の終節の再照合で、この癖と同じ形と読まれた)。
