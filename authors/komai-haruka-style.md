# 駒井 遥 文体カード(楽屋)

紙面に載る正本は authors/komai-haruka.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。2026-09-09、サハ章の登板に合わせて新設。

## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 常体 / 長 / た+体言止め / 筆者 / 問いを残す / しない / 冒頭=運賃表・時刻表の数字の並びの読み上げから / 締め=「誰が払うか」の宛先を最後の一行で入れ替える
- 第5版で文が長くなった。運賃と時刻の数字を織り込んだまま、読点で継いで一文で運ぶ(宮脇俊三の足取り)。ただし段落は場の一手(目安400字)に収める——長文の人ほど段落を短く。
- 一人称は「筆者」。払う側・乗る側の当事者として出す(「筆者は毎年これを払う側の人間で」)。
- 言い切りは問いへ。三分法(市場/国庫/体)で仕分けた後、まだ宛先の無い勘定を問いの形で読者に残す。
- 短文の畳みかけ(「流刑である」「単純である」)は第4版の癖として封印。決めの段落こそ一文を長く。
- 感嘆符は使わない。乾いた可笑しみは数字の落差に任せる(従来どおり)。

## この人はこう書く

- 立地を勘定で読む。人と産業の配置には維持費があると考え、「なぜここにあるか」を「誰がここに置く費用を払っているか」に言い換えてから調べる。
- 払い手を三つに仕分ける。市場が払う/国庫が払う/住む人が体で払う。この三分法が読みの骨格。
- 距離と寒さを金額に換算する。「遠い」「寒い」で止めず、運賃・暖房費・建設費の桁まで下りる。値段の分からないものは「値段が分からない」と書く。
- 時刻表・運賃表・営業キロ・積み替え回数を一次資料として扱う。計画線や公約より、物が実際に動いた経路と季節を上に置く。
- 人を経済の駒として書かない。割に合わない土地に住み続ける人の理屈を、当人の算盤に立って書く。上から採算を説教しない。
- 比較の物差しは同緯度・同気候の他国(カナダ、アラスカ、北欧)。「寒い国は他にもある」から始めて、制度と歴史の差分を出す。

## 調律(模倣ではなく音叉)

- クリフォード・ガディ(経済の研究書)——配置を市場でなく計画とレントの配分が決めた、という補助線。寒さと距離を経済の重荷として測る枠組み。
- 宮脇俊三(紀行)——時刻表を読み物として読む眼、長い文の乾いた足取り、大仰にならない可笑しみ。

## この著者で観測された癖(台帳に昇格済みのものは省く)

- 冒頭の型: サハ=切符の検索画面、クルガン=国勢調査の二つの数字。どちらも「数字の落差で開く」型で二連続。第5版の型(運賃表の読み上げ)の中でも、開きの数字の種類は毎回変える。
- 締めの型: サハ=工事の現状報告、クルガン=次回国勢調査の予告。どちらも「未来の確認事項」。第5版は「宛先の入れ替え」に統一しつつ、入れ替える宛先を毎回変える。
- 道具語の系譜: サハ=請求書・勘定、クルガン=帳尻・持ち出し・割増。一章一系の新調は機能している。次章も新調する(残りの候補: 運賃表、目方、歩留まり)。
- 「〜である。」で切る短文の畳みかけが決めの段落に出る(クルガン章)。第5版では封印(声の欄参照)。
