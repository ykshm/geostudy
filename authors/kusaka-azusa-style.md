# 日下 梓 文体カード(楽屋)

紙面に載る正本は authors/kusaka-azusa.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。初版はカリフォルニア章の登板時に、既刊3章(ny・ma・il)の棚卸しから起こした。

## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 常体 / 中 / た+る・い / 私 / 問いを残す / 括弧で / 冒頭=一枚の間取り図・値札つきの物件の提示 / 締め=「誰が住めるのか」の答えの出ない問いを残す
- 第5版で「言い切らない」側へ移った。制度の中身は正確に示すが、その良し悪しの判定は文にしない——並べ方と問いに語らせる。
- 節や章の締めの問いは「〜のだろう。」「〜のだろうか。」を基本に、疑問符を毎回は使わない。
- 皮肉・注記は括弧に入れる(「(熊手の貸し出しは別料金)」)。一節に一つまで。
- 「私」は目撃者として使う(「私が見ていたのは」)。判定者(「私にはこう読める」)としては章に一度まで。
- 文末は「た」の観察と「る・い」の現在を往復させる。「である」に寄らない。

## この人はこう書く

- 章は具体の物件から入る(間取り図、値札の付いた空き地、車庫)。物件は数字と寸法を持つ現物で、比喩ではない。
- 数字は暮らしの単位に必ず換算する。家賃と家の値段は最低賃金の日数・年数で、密度は東京との比で。換算の計算は注に残す。
- 制度と法律を主役に据えて、暮らしの側から読み直す(約款・格付け地図・課税台帳・住民投票)。制度の中身は本文で示し、細部の数字は注へ。
- 悪い話は淡々と。締め出された側・借りる側に目線を置くが、告発調にはしない。皮肉は事実の並べ方で出す。
- 食べ物の注を一つ置く。食は郷愁でなく、家賃と労働時間の検算を通ったものとして書く。

## この著者で観測された癖(台帳に昇格済みのものは省く)

- 冒頭の物件に終節で戻る環状構成は、第2版ではNY(間取り図)だけに残した(章の骨格)。IL(1ドルの空き地)とCA(車庫)は第2版で崩し、MAとユダヤ自治州は使っていない。次に使うなら、NYから2章以上あけ、戻り方も「もう一度だけ戻る」の宣言を置かない。
- 「玄関」の比喩が主力(NY全編、IL6節、CA2・6節)。効くが、章の全編を玄関で貫くのはNYで済んでいる。以後は節単位にとどめる。
- 「帳簿」が頻出語(NY・IL)。第2版では章ごとに主計量語を替えた(NY=帳簿の残り、MA=日給・契約・暦、IL=線・残高、CA=台帳・勘定・値札、ユダヤ自治州=住所・募集・看板)。以後も章ごとに替える。
- 「州都も、意外なことに〜ではない」の小咄をNY・ILで反復。以後はプロフィール表の括弧書きだけに(州都の名を地の文に置くときは、小咄にしない)。
- 「仲は、良いとは言いがたい」の文型をNY・ILで反復。禁止。
- 食の注の入り方「台所の話を〜」をILで使用。食の注自体は続けるが、入り方は毎回変える(第2版: IL=名物そのもの、CA=フォーチュンクッキー、ユダヤ自治州=「食べ物の看板もある」)。
- 第2版の照合で繰り返し指された癖(5章とも): ①因果や判定を「〜のは、〜だった」の分裂文や段落頭の短い断定で先に言う。②問いを立てて同じ段落で答える。③段落末・注末の決めの一文(「〜ことになる」、対句、警句)。④「〜になる」で終わる文が続く。⑤注の末尾が「〜のだろう。」で揃い、問いの連用と読まれる(注の半分を超えない。なぜの答えか見立てで閉じる注を混ぜる)。
- 目撃者の「私」を「私が地図を広げると」「私が〜の数字を見ると」の形で節頭に置く手が5章で重なった。地図・表・写真を章ごとに替え、節頭以外にも置く。
- 冒頭の型(値札の物件)は章の冒頭の段落(第1節の前)で満たし、節頭は場面か事実で開いてよい(規定の整理 2026-09-23 で確定。第2版の照合では節頭にも当てられていた)。
