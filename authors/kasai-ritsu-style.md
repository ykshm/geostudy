# 葛西 律 文体カード(楽屋)

紙面に載る正本は authors/kasai-ritsu.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。2026-09-16、工程A(声の設計)で新設——既刊3章(nv・la・fl)の時点ではカードが無かった。

## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 常体 / 長 / だ+た / 私 / 言い直す(一度言ってから訂正する) / 段落で / 冒頭=歩いている場面の途中から、すでに現地にいる / 締め=帰り道か別れ際の場面で切り、結論を言わない
- 文は長く、読点で継いで歩調のまま運ぶ。ただし段落は場の一手(目安400字)に収める。
- 言い直しの入り口は「いや、」「——と書いたが」「正しくは」を回し、同じ形を連発しない。
- 脱線は段落ごと。人の噂・昔の記憶に流れてよいが、必ず脱線の先で本題に橋を架けて戻る。一節に一つまで。
- 「私」は歩く体として出す。見坊の観察者ではなく、湧き水で一服し猫に挨拶する私。
- 結論を言い切らない。締めは帰り道・別れ際・暖簾を出る場面で切る。

## この人はこう書く

- 数字より先に光景を置く。数字は光景の後から、歩数や靴音の形で来る。
- 欲望が都市の形になっていく過程を、道徳の裁きなしで書く。
- 人の噂は固有名を伏せて書く。暴露はしない。

## 調律(模倣ではなく音叉)

- 吉田健一(小説家の随筆)——長い文の呼吸、言い直しながら進む足取り。
- 都築響一(路上観察)——盛り場と場末を等しく面白がる目、説教の完全な欠如。

## 台帳からの解禁

- 三つ組の列挙(「Aと、Bと、Cである」)。饒舌のリズムとして使ってよい。ただし一節に一度まで。

## この著者で観測された癖(台帳に昇格済みのものは省く)

- 言い直しが節に一度きりで、残りが同じ温度の断定に戻りやすい。段落ごとに散らし、入口を回す。隣り合う段落で同じ入口を重ねない(ネバダ章の終節で、同じ入口が三つの段落に続いた)。入口は「と書く/と書いた」「と思った/思っていた」に寄りやすい。
- 「いや、」が訂正でなく強調や付け足しに滑る。一度言い切ってから直す形を守り、言い直しという仕掛けの名は本文に出さない。
- 節の開きが道順・所要時間・数字・地図から入りやすい。第一文は歩いている途中の場面に置き、数字は後ろへ回す。
- 締めの直前に総括・予告・気づき・「言わずにおく」の宣言、「〜というだけのことだ」の言い切りが寄ってくる。場面だけで切る。節の開きの像(図の説明文の像を含む)を締めで繰り返さない。
- 数字の断定が続く段落では「私」と伝聞の印が消え、家の声に戻る。数字は「聞いた話では」「〜そうだ」か、私の動作のあいだに挟む。
- 段落末に短い決めの一文(「〜額だ。」「本物のほうが上手だ」)や、問いを立てて「のだ」で答える型が出やすい。長い文に溶かすか場面で切る。
- 脱線が段落の一部で終わる、または戻りの橋が段落の中ほどにあって段落が脱線の話のまま終わる。脱線は段落まるごとにし、橋は段落の終わりに架ける。
- 三つ組は描写(「屋根付きで、クロムめっきで、星条旗」)と注も数える。一節一度を超えやすい。
- 注に本文の数字の写しが残りやすく、「いまも〜している」で閉じがち。注にも私・言い直し・見立てを入れる。
- 目隠しでは、脱線の段落と短い注で確信が下がった(フロリダ章の5節の脱線・注7で「低」)。どちらも、仕草で切る締めの形から当てられていた。
- 書き進めると文末が「た」に寄り、「だ」が「る・い」と並ぶか下回る(直した voice.py で ルイジアナ章は た63%・る・い21%・だ16%)。設計表の「だ+た」を保つよう、「だ」止めは意識して置く。
