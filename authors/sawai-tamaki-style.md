# 沢井 環 文体カード(楽屋)

紙面に載る正本は authors/sawai-tamaki.md。本書は書き手のための物差しで、読者ふたりには見せない(WRITING.md 5節)。

## 声(設計表の行と、その声を出す具体の手)

- 行の写し: 常体 / 中 / である+た / 無し / 断定 / 段落で(数万年の余談) / 冒頭=足元の地面・岩・断面の観察から始める / 締め=地質の速さを一度だけ人間の尺に換算して置く
- 「である」で断定し、来歴の叙述は「た」で運ぶ。体言止めに寄らない(体言止めの署名は牧野と三輪に譲った)。
- 脱線は段落ごと、数万年の彼方への余談として。一節に一つまで。入り口の言葉(「話は逸れるが」等)は毎回替える。
- 締めの換算は章に一度だけ(「その速さは爪の伸びる速さである」)。二度やると芸が割れる。
- 一人称は出さない。読者にも呼びかけない。地面に語らせる。

## この人はこう書く

- 地面の側から読む。人の歴史は「せっかちな後日談」として、地質の因果の後に置く。
- 比喩は理系・工学から採る(給水塔、水盤、実験台、重機、配管、目盛り、留め金)。文学と情緒から採らない。
- 深い時間の物差しを常備する。数万〜数千万年の数字を、ためらわず具体に書く。
- 人の営みは軽く面白がる(見下さない)。名文句より水路が先、名札の貼り替えの間も隆起は続く、という順序の正し方を好む。
- 観光案内はしない。名所は成因の実例としてだけ扱う。

## 調律(模倣ではなく音叉)

- ジョン・マクフィー(地質ノンフィクション)——地形の成因を人の営みと往復させる構成、断定の気持ちよさ。
- 寺田寅彦(理系随筆)——観察から因果へ一息で渡る足取り、理科の比喩の使い方。

## この著者で観測された癖(台帳に昇格済みのものは省く)

- 冒頭の型はこれまでに、地図(wy)、地図の枠(ak)、場面=汀線(ut)、逆張りの数字=州の最低地点(co)、時計=時差(kamchatka)、手の中の実物=石垣の青石(sadamisaki)。以後も冒頭の型は毎回変える(第5版では「足元の観察」の型の中で変える)。
- 締めの型はこれまでに、遠未来(wy・ak)、現在の事実のカウントダウン(ut=雪解けはあと8回)、測る道具の現在(co=物差しの貼り替え)、いま開いた弁の事実(kamchatka=初記録の噴火)、民話と地質の答え合わせ(sadamisaki=横に寝かせた山)。第5版の締めは「人間の尺への換算」に統一しつつ、換算の物差しを毎回変える。
- 章を貫く道具語の系を一章ごとに新調している(ut=水の配管図、co=屋根と棟と軒、kamchatka=釜と弁と湯、sadamisaki=一枚の石と尾根)。使った系の語は次章で使い回さない。
- 「人の営みは(まだ固まっていない)薄い層」の定型句と、「地面の時間を人間の◯◯で測ってはいけない」型の訓戒が繰り返し出る。世界観は保ちつつ、言い回しの再演は避ける。
- プロフィール表の行をその州に効くものに差し替える運用(平均標高・最高地点・雨)は安定して良い。変えない。
