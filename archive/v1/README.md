# archive/v1(第4版までの紙面)

第4版までに書かれた章の旧版と、その -check の保管場所。文体改稿(第5版)の
工程で、改稿の直前にここへコピーされる(docs/文体改稿の手引き.md 5節)。

- 読書会で読まれた章の旧版はここにある。既存の転写の照合は旧版に対して行う。
- 執筆では読まない(CONCEPT.md 7節)。
- authors/ には、第4版の著者の正本・文体カード・文体台帳・章の割り振りを置く(2026-09-14、main の e473e53 の時点。第5版の規定を入れる前の最後の状態)。葛西 律の文体カードは第5版で新設したので、ここには無い。

## 読書会への引き継ぎ(2026-09-24、文体改稿の工程D)

- 2026-09-16〜09-24 の文体改稿で、44章すべてが第5版の声(第2版の本文)に替わった。改稿の前に読書会で読んだ章は、ここにある旧版で読まれている。
- 旧版の全体(本文・規定・著者)がそろった最後の状態は、main の e473e53(2026-09-14)。
- 転写の照合: 場の道具の `geostudy.py check` は、リポジトリの最新の本文とだけ突き合わせるので、旧版で読んだときの転写は NG になる。旧版に対して照合するときは、e473e53 を取り出した別の置き場所を GEOSTUDY_DIR に指定して掛ける(例: `git clone https://github.com/ykshm/geostudy.git ~/geostudy-v1 && git -C ~/geostudy-v1 checkout e473e53` のあと `GEOSTUDY_DIR=~/geostudy-v1 python3 geostudy.py check 転写`。取り出した版は更新されないので、手元の版のまま照合される)。
- しおり: 場の道具のしおり(「章 節-段落」)は、節の中の本文・図・表・注をすべて数えた番号である。段落を割らなかった21章は、旧版で付けたしおりがそのまま同じ段落を指す。次の23章は、下の節の、示した段落から先の番号が動いた(主に400字を超えた段落を割ったため。梶谷の幕間3篇は、注を節の末へ移したため)。そこで止めたしおりは、旧版の段落の書き出しを新しい版で探して付け直す。
