- 段落末を「いまも〜しています」「今日も」で閉じない(手引き8節)。
- 常体の混入を出さない: 地の文の問い(〜のか。)、形容詞や「〜ない。」の言い切り、動詞の終止形の実況。
- 同じ敬体の語尾を三つ続けない(です・ます・ました・ません・でした を回す)。

③今回の軸

- 一枚の葉の死後の収支。ブライトリーフ煙草が稼いだ金と空けた土地が、大学・電力と繊維・銀行・研究団地・豚と芋へどう払い出されたかを、品目ごとに金額と年で板書し、終節の末で差し引きを一行に畳んで閉講する。
- 文の長さは「中」の上のほうに置く(戸川の章と平均文長が重なったため)。敬体の文は接続でつないで長めに組み、数字と品目は体言止めで短く切る。

④声の確認

- 敬体 / 中 / 敬体+体言止め / 筆者 / 断定 / しない / 冒頭=作物の名を挙げ『今日はこの作物の話をします』と開講する / 締め=収支の総括を一行で述べ『以上です』と閉講する(設計表の「」を『』に替えて写した。selfcheck が禁句と読まないため)
- 運用の解釈: 開講と閉講は章に一度ずつ(章頭の段落と終節の末)。節の頭は、その節で扱う品目を作物の側から一文で告げる。節の末は事実か数字で閉じる。
