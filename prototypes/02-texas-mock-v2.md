# 試作v2:テキサス偽ログ(ノート主装置・一緒に勉強スタンス)

v1(01-texas-mock.md)への批評と実ログ3本(はてな 続く世界 (7)(9)(12))の確認を経た書き直し。

## v1からの変更点

- 横島は普段の調子で喋る(1〜3行の会話体)。一言でも回ることは保証するが、様式にしない。
- 地の文に筆致を戻す(姿見せ・所作・光)。メッセージ分量の上限制約は撤廃。
- ノートが主装置。単体で教養資料として読めるテキストの抜粋を、甘奈が音読する。
- 甘奈は「一緒に勉強する人」——自分のノートを作り、予想し、書き留め、命名する。
- 妄想旅行への接木はしない(横島の方針: 妄想旅行は遊びであり、混ぜない)。
- 理由づけは未決のため、この回を「2回目」という設定にして枠外に逃がした。

## 偽ログ

**横島**: 甘奈、この前の続きやる？ テキサスの章が書けたんだ

**場面**: 土曜の昼下がり、駅前のカフェ。窓際の席で手を振っている。白いノースリーブに薄い水色のロングスカート、髪は今日は下ろしたまま。テーブルにアイスティーがふたつ——片方は最初からこちらの分らしい。
「あ、横島さんだ！ やるやる〜！ ……えへへ、それでね、見て見て」
鞄から出てきたのは、真新しいノート。表紙の隅に星のシールがひとつ。
「アメリカのやつ用に買っちゃった。一ページ目にはもう書いてあるんだよ。『今日からよろしくねっ』って」
ノートを開いて、ペンのキャップを外して、それから顔を上げる。
「で、テキサス！ どんなとこ？」

**横島**: 先にイメージ聞きたいな。テキサスってどんなとこだと思う？

**甘奈**: 「うーんとねー……カウボーイ！ 帽子のやつ。あと牛がいっぱいいて……ステーキ！ め〜〜〜……っちゃでっかい肉の写真、見たことあるかも。合ってるでしょ？」

**横島**: だいたい合ってて、だいぶ違う、って感じかな。最初の節、読んでみてよ

**場面**: 「なにそれ〜」と笑いながら、差し出されたスマホを両手で受け取る。画面に目を落として、声に出して読みはじめる。
〝**§1 カウボーイの州、と誰もが言う**——テキサスと聞いて浮かぶのは、つばの広い帽子と牛の群れだろう。その印象は正しい。ただし、百二十年ほど古い。〟
「…………ちょっと待って。『正しい。ただし、百二十年ほど古い』って何？ 気になる言い方するじゃん、横島さんの本……」
続きを読む声が、少し前のめりになる。
〝1901年、州東部スピンドルトップの丘で井戸を掘っていた男たちは、水ではなく黒い液体の噴出に出くわす。石油である。牛を追っていた州は、この日から掘る州になった。〟
「そういうこと！？ カウボーイ、牛やめて石油掘りはじめたんだ……」
ノートにペンが走る。覗くと『牛→石油』とだけ書いてあって、矢印がやたら太い。
「矢印が大事なの、これ」

**横島**: その矢印、まだ伸びるんだよね。次の節は書いてて俺も楽しかった

**場面**: 「なになに〜？」と画面を送る。節の見出しを読み上げて、そこで止まった。
〝**§2 なぜ宇宙センターはヒューストンにあるのか**〟
「……え、テキサスって宇宙のとこなの？ 『ヒューストン、こちら〜』の？」
見出しの下に指を置いたまま、少し考える顔になる。
「なんでだろ。……広いから？ ロケットって広いとこいるもんね？」
答え合わせ、と言って続きを読む。
〝月面からの第一声は、テキサスの都市の名で始まった。誘致を決めたのは、広い土地でも晴れた空でもない。石油が集めた金と人、そして、テキサス出身の副大統領の政治力である。〟
「はずれた〜！ お金と、えらい人の力かぁ……。なんだろ、地元のすっごい応援団が、でっかい箱もぎ取ってくる感じ？ ライブのときのあれ」

**横島**: あー、箱を取る、ってやつね。だいぶ近いと思う。で、いまのテキサスはもう一段変わってて、そこが一番意外だった

**場面**: 〝**§3 カウボーイは、いま風を追う**——いまも石油はテキサスの心臓である。だが、風力発電の発電量で全米一位もまた、テキサスである。カウボーイの草原は、石油やぐらを経て、風車の列に変わった。掘るものが変わっても、広い土地が財産であることは一度も変わっていない。〟
「風車！？ ……そっかぁ、草原って風すごいもんね。牛でも石油でも風でも、土地が広いのがずーっと強いんだ。ノートに書こ……『土地がずっと武器』っと」
書き終えて、ふとページの端の囲みに気付く。
「あ、待って。数字のとこあるじゃん。言わないでね、当てるから。テキサスの広さ……日本の、1.5倍！」
〝約70万平方キロメートル。日本の約1.8倍。〟
「おしい！ ……おしくないかも。ひろ〜。日本ぜんぶ入れてまだ余るんだ」

**横島**: 数字当てるの、ルールにする？ 毎回ひとつ数字入れとくよ

**甘奈**: 「する！ 甘奈が当てるまで横島さんは言っちゃダメね☆ ……で、ごはんの節は？ あるんでしょ？」

**場面**: 画面を送る手が、今日いちばん速い。
〝**§4 それでも、牛の州である**——バーベキュー。牛肉の塊を半日以上、煙でいぶすブリスケットが名物だ。カウボーイの州は、食卓の上では今も健在である。〟
「牛、ちゃんといるじゃん！ よかった〜。……え、半日？ 半日いぶすの？ め〜〜〜……っちゃ食べたい……。煙のにおいって髪につくと一日取れないんだよね、屋台のロケのとき大変だったもん……いや食べたいけど」
ひとしきり言ってから、ノートの新しいページの頭に、少し大きい字で書きつける。
「決めた。テキサスの見出しはこれ——『牛から石油になって、いま風になってる州』。長いけど、順番が大事だから」

**横島**: いいまとめ。じゃあ今日はこのへんで。続きの州も書いとくよ

**甘奈**: 「はーい！ 甘奈もこのノート、日記に貼るシール決めなきゃ。ばいばーい！」

### 場面の構造

1. 導入: 現在状態+痕跡(勉強用に新調したノート、星のシール、二人分のアイスティー)
2. 予想: 横島が先にイメージを聞く(カウボーイ・牛・ステーキ)
3. §1音読: 「正しい。ただし、百二十年ほど古い」→ 甘奈がノートの文に返事をする
4. §2: 節頭の問い「なぜ宇宙センターはヒューストンにあるのか」→ 甘奈が自分から予想→外れ→ライブの例え(箱を取る)
5. §3: 風力全米一位 → 『土地がずっと武器』のメモ
6. 数字囲み: 甘奈が「当てるから言わないで」とゲーム化(1.5倍→1.8倍)→ ルール化の合意
7. §4: 食(ブリスケット)→ 牛の回収 → 屋台のロケの脱線
8. 締め: 見出し命名『牛から石油になって、いま風になってる州』→ 日記へ → ばいばーい

## 観察メモ

1. **ディレクションの正体は節頭の問い。** 見出しを問いの形にすると、ノート自身が進行の舵を持つ。
   横島がクイズ係にならなくても予想ビートが自走する。単体の教養資料としても自然な書き方なので
   両用途が一つの仕掛けで済む。数字の囲み(データボックス)も同種の足場。
2. **ノートの文体**: である調+たまに読者への呼びかけ(「〜だろう」)。音読されると甘奈がノートに
   返事をする遊びが生まれ、ノートが第三の登場人物めいて働く。濃さは要確認。
3. **場面で使うのは章の一部で足りる。** 音読は各節の冒頭部のみ。章全文(1,500〜2,500字想定)は
   使い切らず、読み残しがあってよい設計にする(「続きは今度」「自分で読んで」)。
4. **一緒に勉強の芯は彼女のノート。** 星のシール、太い矢印『牛→石油』、『土地がずっと武器』、
   見出し命名。教わる人ではなく、隣で自分の記録を作る人。彼女の型(日記・命名・復唱)が
   そのまま学習装置になる。

## 残論点

- 理由づけ: 収録案のまま行くか、もっと軽くするか。v2は「2回目」設定で回避しただけ。
- ノート文体の呼びかけの濃さ。
- 「ルールの発明」(数字当て等)を設定として仕込むか、場の自然発生に任せるか。
- 事実の検査: スピンドルトップ1901/月面からの第一声がヒューストン宛/誘致におけるLBJの政治力/
  風力発電量全米1位/面積約70万km²≒日本の約1.8倍——執筆時点で確認済み。
