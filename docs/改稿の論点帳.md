# 改稿の論点帳(楽屋)

文体改稿(docs/文体改稿の手引き.md)の途中で挙がった、手順・道具・規定の側の不備を集め、どう直したかを記す。紙面には載せない。

並行のセッションは、この帳面に直接書き足さない(並行のブランチどうしが衝突する)。各章の -check の「## 規定側の論点」に書き、全セッションが納めてから一つのセッションがここへ集める(手引き7節)。

## 1. 工程Cの集約(2026-09-23)

材料: 工程Cの納品(PR #108〜#118)の報告、44章の -check の改稿と検査の記録、11人の文体カードの更新記録。セッションの会話そのものは読めないので、記録に残った分だけを集めた。11人ぶんのセッションが、同じ不備を別々に見つけ、別々の「当座の解釈」で処理していた。数字は、その不備を記録に書いた著者の数。

凡例: 【道具】scripts/ を直した/【規定】手引き・設計表・照合役の定義を直した/【判断】依頼者が決めた/【裁量】依頼者から裁量を預かって決めた(2026-09-24)

### 1-1. 照合役に章の冒頭(前書き)が渡らない——11人

### 1-2. 冒頭の型・締めの型を途中の節の頭と末にも当てる——11人

- 症状: 照合役が各節の頭に章の冒頭の型、各節の末に締めの型を当てて毎節「開き 否」「締め 否」を出した。セッションの解釈は割れた——章の開きと締めだけと読んだのが日下・風間・駒井・梶谷・千々石、節ごとに倣う運用を規則にしたのが三輪・香月・沢井・牧野・葛西。照合役自身も「章頭だけを指すなら対象外」と留保を付けたり、同じ章で節ごとに合否を割ったりした。往復の上限に達した主な原因。
- 直し:【判断】冒頭の型は章の開き(前書き、無ければ第1節の頭)、締めの型は章の締め(終節の末尾)にだけ当てる。途中の節に倣うのは著者の自由で、求めない。【規定】設計表の語彙の欄、手引き5節、照合役の定義(判定の範囲)。【道具】`shogo` の文面の頭に、一節の位置と「開きの軸/締めの軸: 判定する/対象外」を置く。文体カードのうち、照合役が節ごとに当てると書いた行(駒井・日下・沢井)を書き直した。

### 1-3. 往復の上限(3回)に達し、指摘が回ごとに入れ替わる——11人

- 症状: 終節の再照合が3回の上限(またはそれ以上)に達した章が34章。同じ文面の同じ軸が合から否に変わった(葛西 fl の文末、千々石 hi の締め、三輪 津軽の文長と一人称、沢井 co・カムチャツカの開き)。1回目の直しが次の否を生んだ(沢井 co の節内の環、葛西 fl)。照合役が前の回で求めたことを、次の回で環状と判定した(梶谷 コンビナート)。
- 原因と直し:
  - 1-2 の範囲の問題。→ 上の直し。
  - `--sai` の文面ではカードの載る節が初回と違った。初回(全文)で合だった開きが、`--sai`(声と観測された癖だけ)で否になった(梶谷 冬道)。逆に `--sai` が載せる「観測された癖」に足したばかりの行が物差しにされた(葛西 fl)。「この人はこう書く」に置いた新しい規則が `--sai` に載らなかった(千々石)。→【道具】カードは初回も再照合も同じ節(声・この人はこう書く・台帳からの解禁・観測された癖)を載せる。更新記録・代表章・調律は載せない。【規定】カードを一つの章の照合の途中で書き換えない(手引き5節)。
  - 照合役が一節しか見ないので、前の節に出た数や名を「初出」「この節に無い」と読んだ(沢井4章、千々石 雲南、牧野 多摩の章の問い)。沢井はカードに「終節の中で数を置き直す」回避策まで置いた。→【規定】照合役の定義: 初出かどうか・章の問いへの答えか・ほかの章との重なりは判定しない。【道具】終節の文面には、参照として章の冒頭の段落を添える(環状構成と冒頭の問いの判定だけに使う)。
  - 据え置き部分(節題・図の行と説明文・引用の訳・出典の行・注の呼び出し順)への指摘が、ほぼ全章で繰り返し出た。→【道具】図の行と説明文は文面から省く。【規定】照合役の定義で照合の対象外。
  - 過検出: 事実の列挙を三つ組に(11人ほぼ全員)、章の中の算術を二度目の換算に(沢井)、出典だけの一行注を帳簿に(梶谷)、出典から来る留保を言い切りの否に(沢井・葛西)、語釈・原語の括弧を脱線に(梶谷)、「章に一度」の類の規定を一節で判定(梶谷の言い直し、牧野の保留の宣言)、足りない寸法や成因を足せと要求(梶谷・沢井・風間)、設計どおりの締めの一文を決めの一文・警句・家の声に(千々石・駒井・牧野)。→【規定】照合役の定義に「判定の範囲」を置いた。
  - 文の長さと文末の偏りを照合役が手で数え、回ごとに数え違えた。→【道具】`shogo` の文面に機械の測定(平均文長・文末の内訳)を入れ、照合役は数え直さない。文の長さは平均を設計表の区分に当てて決める。
- 試し: 工程Cで上限の3回まで掛けて否が残った千々石 hi の終節を、新しい文面と定義で1回掛けた。8軸すべて合(開きは対象外)、台帳・帳簿・家の声とも無し。

### 1-4. 最後の照合・目隠しの後の直しが検査されずに出た——ほぼ全章

- 直し:【規定】手引き6節に、検査の順序(照合→目隠し→機械の検査)と、最後の検査の後に直したら掛け直す決まりを置いた。3回目の指摘を直したら、確認の照合を一度だけ掛け、そこで出た新しい指摘は記録して止める。目隠しは最終稿で、落ちたら掛け直しを2回まで。

### 1-6. voice.py の数え違い——7人

- 【注N】の合図で終わる文を体言止めに数えていた(本文8,003文中675文)。体言止めの割合が膨らみ、平均文長も伸び、`--compare` の最近傍が揺れた。沢井の佐田岬章では第4版の旧版が2位に入るほど測りが寄り、沢井 co・風間は順位を戻すために文を割った。→【道具】合図を落としてから測る。
