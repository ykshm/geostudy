# 画像収集セッションへの引き継ぎ

作成: 2026-08-24。全6章の図版27枚を取得して `text/usa/img/` に置き、mainにマージするまでがこのタスク。完了したら本ファイルは削除してよい。

## 0. 前提(依頼者が事前にやること)

この作業は実行環境から画像ホストへ接続できないと始められない。前回の執筆環境ではネットワークポリシーが wikimedia.org への接続を遮断していた(プロキシがCONNECTに403)。セッションを始める前に、claude.ai/code の**環境(Environment)設定 → ネットワークアクセス**で、以下のドメインを許可すること:

- `wikimedia.org`(サブドメイン含む。実際に使うのは `commons.wikimedia.org` と `upload.wikimedia.org`)— 大半の画像はここから取る
- 予備(Commonsに適切な画像がない場合の直接取得先): `loc.gov`(米議会図書館)、`nasa.gov`、`nps.gov`、`usgs.gov`

設定方法はClaude Code on the webのドキュメント参照: https://code.claude.com/docs/en/claude-code-on-the-web
セッション冒頭で `curl -sI https://commons.wikimedia.org` が200系を返すことを確認してから作業に入ること。遮断されたままなら作業を中断して依頼者に報告する。

## 1. 正本と手順

- **何を取るかの正本は各章の `-check` ファイルの「図版の出所」節**(text/usa/*-check.md)。本ファイルの一覧表(3節)はその集約にすぎず、食い違ったら -check が正しい。
- 取得はWikimedia Commonsの `Special:FilePath` が楽:
  `curl -sL "https://commons.wikimedia.org/wiki/Special:FilePath/<ファイル名(スペースは%20)>?width=1600" -o <出力>`
  `?width=` を付けるとサムネイル(SVG→PNG化にも使える)。位置図(*-locator.png)はSVGなので `?width=1200` でPNG化する。
- サイズ目安: 幅1200〜1600px、1枚数百KB程度。リポジトリを不必要に太らせない。
- 取得したら `file` コマンドで実体を確認(HTMLエラーページを画像として保存していないか)。

## 2. ライセンス検証(必須)

- 使えるのは、公開の場に置ける権利のもの——パブリックドメイン(米連邦政府職員の職務著作を含む)か、再配布可のCCライセンスのみ(WRITING.md 2節)。
- **各章の本文キャプション末尾には、想定ライセンスが既に書いてある**(例:「(写真: 米内務省開拓局、パブリックドメイン)」「(写真: Matthew T Rader, matthewtrader.com, CC BY-SA 4.0)」)。取得した実ファイルのライセンスがこの表記と一致することをCommonsのファイルページで確認すること。
- 別の画像を採用した場合は、キャプションの帰属表示を実ファイルに合わせて修正する(これは「誤りの訂正」にあたる通常の編集で、可)。修正したら該当章の -check にも記録する。
- CC BY / CC BY-SA の画像は作者名とライセンス名の表示が必須。PDのものは「パブリックドメイン」と記す。

## 4. 配置・検証・納品

1. 画像を `text/usa/img/` に置く(位置図はキャプションの「赤く塗られている」等の描写と実画像が合っているか目視確認)。
2. `pip install markdown && python site/build.py` を実行。**「画像が未収録」の警告が27件→0件になることを確認**(サイトビルドが検証を兼ねる)。
3. キャプション修正があれば該当章と -check を更新。
4. コミット→ブランチにpush→PR→mainへマージ。マージでPagesワークフローが走り、https://ykshm.github.io/geostudy/ に画像入りで自動反映される。
5. 各 -check の「図版の出所」に、実際に採用したファイル名・作者・ライセンス・取得日を確定情報として追記する。

## 5. できなかった場合

- 一部が見つからない/ライセンス不明なら、その画像は入れずに残りだけ納品し、未了分を -check に記録して依頼者に報告する。ライセンスが怪しいものを妥協して入れない。
