# 臥遊風土記 執筆セッション 手引き

第2シリーズ「臥遊風土記」の章を、セッションごとに一章ずつ書くための手引き。紙面に関する決まりはすべて CONCEPT.md / WRITING.md / text/japan/series.md が正本であり、本書は繰り返さない。本書が定めるのは、一回のセッションの範囲と工程、依頼の文面だけである。

## 依頼文の雛形

新しいセッションに貼る文面。問いだけ差し替える。

> 臥遊風土記の新しい章を書いてください。問いは「○○」。
> まず docs/臥遊風土記の執筆セッション手引き.md を読み、そこに書かれた工程で進めてください。
> 切り口の提案の段階で一度止まり、確認を求めてください。

問いは、ふわっとしていてよい。「八丈島って何ができるの?」「青森って意外と大きいよね」で足りる。

## 一回のセッションの範囲

- 一問一セッション。
- 成果物は WRITING.md 1節6項の通り——章ファイル/-check ファイル/img/ の画像/著者を新しく立てたなら authors/ の正本と割り振りの一覧の行。
- ウェブ版の地図は、章のマージ後に別に依頼する。このシリーズでは標準の工程である(text/japan/series.md 11節)。

## 工程

1. ブランチを切る(mainには直接コミットしない)。
2. CONCEPT.md → WRITING.md → text/japan/series.md → authors/index.md を、この順で読む。
3. 下調べ——問いの前提を検証し、材料の当たりをつける。ここで、問いが章に育つかを見る。育たなければ、広げる・ずらす案を提案に含める。
4. 提案——切り口を2〜3案(推し1案)、確認を得る。書式は下。
5. 著者を決める——提案で示した著者を確定する。既存なら、プロフィールと同じ著者の既存章を必ず開いて読む。新設なら、書く前に立てる(WRITING.md 3節)。
6. 章を書き、検査する(WRITING.md 1節・4節)。
7. 図版を集める(text/japan/series.md 10節)。位置の図を忘れない。
8. site/build.py を実行し、警告が出ないことを確かめる。
9. コミットし、pushし、PRを立てて報告する。マージは依頼者の指示を待つ。
10. マージ後、地図の工程へ(site/MAPS.md)。

## 提案の書式(工程4)

短く。案ごとに次を一行ずつ。

- 切り口——章を何で貫くか
- 縮尺と範囲——どこからどこまで、何で回るか、何日分か
- 著者——既存の誰か、新設ならどんな人か(職業・癖・土地勘)
- 節の並び——題の一覧(目安5〜7)
- 答え——この案で、問いに何と言い切るか

最後に、推しとその理由を一行。
